## Programs

### 1. Employee Payroll System

A simple employee payroll system that stores employee details and calculates salary based on the employee's basic salary and other components.

The program demonstrates how OOP concepts can be used to manage employee information and perform payroll-related calculations.

**Concepts used:**

* Classes and Objects
* Inheritance
* Encapsulation
* Constructors
* Function overriding
* Polymorphism
* Virtual functions
* Salary calculation


### 2. Payment Gateway System

A simple payment system demonstrating an abstract base class and different payment methods such as Credit Card, UPI, and Net Banking.

**Concepts used:**

* Abstraction
* Inheritance
* Virtual functions
* Runtime polymorphism
* Smart pointers

### 3. Vehicle Fleet Management

A vehicle management program containing different types of vehicles such as Truck, Delivery Van, and Delivery Bike.

**Concepts used:**

* Inheritance
* Function overriding
* Virtual functions
* Runtime polymorphism
* STL Vector

### MINI_PROJECT : Banking System

A menu-driven banking system with different types of accounts: Savings Account, Current Account, and Fixed Deposit Account.

The program allows the user to enter account details and perform basic operations such as deposit, withdrawal, account information display, and interest calculation.

**Concepts used:**

* Inheritance
* Abstraction
* Polymorphism
* Virtual functions
* Dynamic memory allocation
* Menu-driven programming

## How to Run

1. Clone or download this repository.
2. Open the required `.cpp` file.
3. Compile the program using a C++ compiler.
4. Run the generated executable.

Example:

```bash
g++ program.cpp -o program
./program
```
